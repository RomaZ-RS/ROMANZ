# TaskFlow

TaskFlow — это удобное веб-приложение для создания задач, планирования дел и отслеживания прогресса.

Проект помогает организовать рабочий процесс, не забывать о важных задачах и эффективно распределять время.

## Возможности

- Создание новых задач
- Редактирование и удаление задач
- Отметка выполненных задач
- Разделение задач по категориям
- Установка приоритета
- Удобный и понятный интерфейс
- Адаптивная версия для компьютера и телефона
