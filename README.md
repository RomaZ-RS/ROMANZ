# **OOO.RS**

**OOO.RS** — это **современное веб-приложение** для создания задач, планирования дел и отслеживания личного или рабочего прогресса.

Приложение помогает **организовать повседневные дела**, правильно расставлять приоритеты и контролировать выполнение задач. С помощью **OOO.RS** пользователь может удобно хранить список задач в одном месте и не забывать о важных событиях.

## **О проекте**

**OOO.RS** создано для людей, которые хотят **эффективнее планировать своё время** и поддерживать порядок в делах.

Приложение подходит для:

- **Учёбы**
- **Работы**
- **Личных целей**
- **Планирования проектов**
- **Организации домашних дел**
- **Ведения списка покупок**
- **Контроля ежедневных задач**

Главная цель проекта — сделать планирование **простым, понятным и удобным** для каждого пользователя.

## **Возможности**

- **Создание новых задач**
- **Редактирование существующих задач**
- **Удаление ненужных задач**
- **Отметка выполненных задач**
- **Просмотр списка всех задач**
- **Разделение задач по категориям**
- **Установка приоритета для каждой задачи**
- **Добавление описания к задаче**
- **Указание даты выполнения**
- **Сортировка задач**
- **Поиск по списку задач**
- **Фильтрация выполненных и невыполненных задач**
- **Удобный и понятный интерфейс**
- **Адаптивная версия для компьютеров, планшетов и телефонов**
- **Простая навигация между разделами**
- **Быстрое добавление новых задач**

## **Основные разделы**

### **Все задачи**

В этом разделе отображаются **все добавленные задачи пользователя**.

### **Активные задачи**

Здесь находятся задачи, которые **ещё не были выполнены**.

### **Выполненные задачи**

В данном разделе отображаются задачи, отмеченные как **выполненные**.

### **Категории**

Задачи можно распределять по категориям:

- **Работа**
- **Учёба**
- **Дом**
- **Спорт**
- **Покупки**
- **Личные дела**

### **Приоритеты**

Для каждой задачи можно выбрать уровень важности:

- **Низкий**
- **Средний**
- **Высокий**

Это помогает понять, какие задачи нужно выполнить **в первую очередь**.
